# Portfolio

Base de portfolio con Astro, React, TypeScript, Tailwind y Anime.js.

## Local

```bash
npm install
npm run dev
```

## Personalizar

- Datos: `src/data/content.ts`
- Página: `src/components/Site.tsx`
- Estilos: `src/styles/global.css`

## Deploy

GitHub Actions publica en Pages al hacer push a `main`.
La URL queda en `https://markush0f.github.io/portfolio-base/`.
